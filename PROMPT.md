## 0. Правила поведінки в цьому проєкті
- Відповідати українською, коротко, по суті. Команди для терміналу: Windows, bash UCRT64 → **прямі слеші** або шляхи в лапках.
- Перед правкою скрипта **звіряти, що користувач завантажив актуальну версію**: у першій сесії `face_stage.py` на диску не мав
  `--others-ratio/--id-filter`, хоча в нотатках вони були (`grep` по файлу перед патчем). Файли в репо = джерело істини.
- Нічого не стверджувати без перевірки: поріг 0.5/0.4 для `--id-min-sim` не валідований; facenet у моєму sandbox не запускався
  (лише numpy-частини та stub-прогін); torch-частини flame_ams перевіряв тільки користувач.
- **Не перебільшувати результат.** Формулювання: «слабкий, статистично значущий, пошуковий зв'язок понад стать, без контролю
  віку»; НЕ «голос визначає обличчя» і НЕ «сигналу немає». Раніше я помилково сказав «сигналу немає» при n=17 — коректно було
  «немає надійних доказів».
- Основну метрику зафіксовано ДО перегляду результатів: **середній r_within по піднабору з targets.json + пермутаційне p
  (перемішування голосів усередині статі)**. Окремі AM/PC — лише пошукові (winner's curse, множинні порівняння, критичне |r|
  для n=28 ≈ 0.37 без поправки).
- Помилки визнавати прямо, без самобичування. Не питати більше одного уточнення за раз.
- Користувач не може зараз добути вік дикторів і більше дикторів (30 — максимум). Не наполягати; вік = задокументоване обмеження.
- Цей файл оновлювати та надавати разом із кодом задля збереження прогресу дослідження.

## 1. Мета й пайплайн
Speech-to-Face (курсова): голос → антропометричні індекси (AMs) обличчя. Псевдорозмітка AMs: FLAME 3DMM підганяється до
landmarks MediaPipe → нейтральна форма β → безрозмірні індекси. Спікери — публічні особи, id 1..30, `dataset/meta.csv`
(без заголовка: `id,ім'я,стать m/f,clip`).

Середовище: Windows, `D:\study\1_flame\`, conda-env `flame` (Python 3.10, numpy<2, **torch 2.14.1+cpu**, scipy, opencv-python,
mediapipe, speechbrain, soundfile, facenet-pytorch). GPU не використовується (MediaPipe Tasks на Windows лише CPU; решта — малі
навантаження). Не пропонувати перехід на CUDA без причини (ризик зламати numpy/mediapipe).

Встановлення facenet (пастки, на яких втратили час):
`pip install facenet-pytorch --no-deps pillow requests tqdm` (**tqdm**, не tqd) + `pip install torchvision==0.29.1 --no-deps
--index-url https://download.pytorch.org/whl/cpu` (пара до torch 2.14.1; `--no-deps` обов'язково, інакше pip псує torch/numpy).
Ваги VGGFace2 качаються при першому запуску.

## 2. Скрипти (усі в корені; останні версії = у репо)
1. `face_stage.py` — відбір кадрів + 478 landmarks MediaPipe → `faces/<id>.npz` (landmarks, files, yaw, roll, pitch_rel, sharp,
   id_sim). Прапорці: `--auto-sharp --min-sharp --max-yaw --max-roll --max-mouth --min-face-px --min-keep --preview prev`,
   `--others-ratio R` (0 = рівно одне обличчя; R>0 = беремо найбільше, відкидаємо кадр, лише якщо друге ≥ R×; 0.3 → ПОСЛАБЛЮЄ
   відсів, терпить крихітні фонові обличчя), `--id-filter` (facenet, домінантна ідентичність: медоїд → центр кластера → поріг
   косинуса `--id-min-sim`, дефолт 0.4; друкує `id sim kept: median/min; dropped; share`, попередження `!!` якщо share<50%;
   `prev/<id>_otherperson.jpg` = відкинуті обличчя найближчі до порогу з їх sim). Причини відсіву: unreadable, no_face,
   other_faces, small, other_person, blurry. MediaPipe: num_faces=4.
2. `flame_ams.py` — підкоманди inspect, selftest, labels, reliability, analyze, mesh. Підгонка FLAME до 105 внутрішніх точок
   (ембедінг без контуру/підборіддя/вилиць: ids 1,152,172,234,397,454 відсутні → ширина обличчя/щелепа/підборіддя недоступні).
   Нормалізатор усіх індексів: відстань між зовнішніми кутами очей (33–263). `labels --min-frames 3` (спікери з <3 кадрами
   пропускаються), фільтр якості за fit_rms.
3. `voice_stage.py` — ECAPA-TDNN (speechbrain, 192-d), сегменти 4 с, кап 40/спікер → `voices.npz`.
4. `regress_stage.py` — ridge (dual, стандартизація, alpha через внутрішній LOO), leave-one-speaker-out; метрики r_all,
   r_within (всередині статі), r_sex (проста кореляція AM зі статтю, in-sample); PCA-цілі; два пермутаційні тести
   (між усіма / всередині статі; виводить null-середнє, бо LOO-r зміщений); **`--exclude 1,2,8`** (чутливість; пише в
   `results_excl_<ids>.csv`); **`--controls faces`** (негативні контроли: log_sharpness, log_face_px, mean_abs_yaw,
   mean_abs_roll як цілі тією ж моделлю й тим самим within-sex тестом). `--perm` дефолт 200, для фіналу 2000.
Усі скрипти мають `--selftest` (синтетика, без даних/моделей, крім torch-частин flame_ams).

## 3. 18 AMs і піднабір
nose_width, nose_length, nasal, mouth_width, mouth_nose_ratio, intercanthal, eye_width, brow_distance, brow_nose, midface,
eye_mouth, philtrum, lip_height, nose_protrusion, eye_height, brow_eye, upper_lip, lower_lip (усі `*_idx`, окрім nasal_index
і mouth_nose_ratio). Піднабір `targets.json` (n=28): **15/18**, відкинуто intercanthal (≈ −0.98 з eye_width), nose_length
(0.93 з midface), nasal_index (−0.87 з nose_protrusion). PCA: 5 компонент = 90% дисперсії. Вибір піднабору — лише з міток,
без голосу (витоку немає).

## 4. Результати (30 дикторів, власно зібраний датасет для тестової перевірки → 28 у регресії; 15 f / 13 m)
- face_stage: 30/30 мають ≥2 кадри; id-фільтр працює (медіани sim 0.84–0.97, жодного `!!`; відкинуті в `*_otherperson` —
  підтверджено користувачем візуально: це справді чужі). Слабкі: 3 і 9 (по 2 кадри, без міток), 1 і 8 (по 3 кадри).
- labels: 28 ідентичностей, всі пройшли fit-фільтр (rms 0.0176–0.0265). reliability (26 спікерів): усі 18 AMs ok,
  r_SB 0.82–0.96 (лише стабільність у межах одного відео, не валідність).
- voice: 30 спікерів, 1136 сегментів, 192-d (спікери 1 і 2 мають лише 17 сегментів).
- **regress (n=28)**: mean r_all 0.31, **r_within 0.13**; пермутація між усіма p=0.002; **всередині статі p=0.028** (2000,
  null r_within −0.08). Найкращі r_within: eye_mouth 0.56, midface 0.53, brow_nose 0.45, lower_lip 0.38; PC1 r_within 0.44
  (eye_mouth/midface/nose_length — по суті один сигнал вертикальних пропорцій). Високі r_all у lower_lip, mouth_nose_ratio,
  brow_distance, nose_width — здебільшого стать (r_sex 0.6–0.7).
- **Чутливість `--exclude 1,2,8` (n=25)**: r_within 0.15, p всередині статі **0.020** → тримається без слабких даних.
- **Негативні контролі**: середній r_within 0.03, p=0.204 (null −0.08) → в агрегаті чисті. АЛЕ **mean_abs_yaw r_within 0.53**
  (на рівні найкращих AM; грубо p≈0.004 параметрично, ≈0.016 з Бонферроні на 4 — оцінки наближені, LOO-r зміщений),
  log_sharpness −0.26, log_face_px −0.01, mean_abs_roll −0.13. Інтерпретація відкрита: (а) ембедінг голосу кодує тип відео,
  від якого залежить поза — нешкідливо; (б) залишковий yaw (до ±20°) зсуває landmarks→AMs і пов'язаний з голосом через умови
  запису — тоді частина зв'язку артефакт.
- Попередній прогін n=17 давав p(within)=0.139; ширша вибірка звузила невизначеність, а не «підтвердила» окремо (17 із 28
  ті самі спікери).

## 5. Відкриті задачі (в порядку пріоритету)
0. Додати діаграми результатів для наочності ознайомлення користувачем. не обмежуючись сухими цифрами.
1. **Прапорець у regress_stage.py, що прибирає вплив mean_abs_yaw (за бажанням log_sharpness) з AMs перед регресією**
   (залишки AM після регресії на yaw/sharp, всередині LOO або на всіх — обговорити ризик витоку), і перевірити, чи p(within)
   лишається ~0.02. Також: кореляція самих AM з mean_abs_yaw. Це було запропоновано, користувач ще не відповів «так».
2. Вік — не збираємо (обмеження, записати у висновках). Другий ролик на людину — недоступний.
3. Візуально звірити меші (`flame_ams.py mesh --id N --out pN.obj`) з фото для кількох дикторів.
4. Звіт: використовувати піднабір з targets.json + PC1–PC2 (до 4–5 PC); основний результат = середнє + p; окремі AM пошукові.
5. Текст для висновків (узгоджено): «У вибірці з 28 публічних осіб виявлено слабкий, але статистично значущий зв'язок між
   ембедінгом голосу та AMs обличчя понад стать (p=0.028; стійкий до виключення трьох найслабших спікерів, p=0.020).
   Негативні контролі в агрегаті зв'язку не показали, проте поворот голови (mean_abs_yaw) передбачається голосом так само
   добре, як найкращі AM. Вік не контролювався. Результат пошуковий; потребує незалежної вибірки й різних відео однієї людини.»
6. Можливі розширення (низький пріоритет): ширина обличчя/щелепа (статичний ембедінг FLAME 68 точок / вершини меша),
   зворотний крок (меш за передбаченими AMs), навчання на сегментах.

## 6. Порядок команд (прямі слеші)
```
python face_stage.py --frames dataset/frames --out faces --model face_landmarker.task --preview prev --auto-sharp --min-sharp 12 --max-yaw 20 --max-mouth 0.3 --max-roll 15 --min-face-px 70 --min-keep 2 --others-ratio 0.3 --id-filter
python flame_ams.py labels --flame "flame_data/FLAME2020/generic_model.pkl" --emb "flame_data/embedding/mediapipe_landmark_embedding.npz" --lmk faces --out labels.npz --min-frames 3
python flame_ams.py reliability --flame "flame_data/FLAME2020/generic_model.pkl" --emb "flame_data/embedding/mediapipe_landmark_embedding.npz" --lmk faces --out reliability.csv
python flame_ams.py analyze --labels labels.npz --reliability reliability.csv --out targets.json
python voice_stage.py --audio dataset/audio --out voices.npz
python regress_stage.py --voices voices.npz --labels labels.npz --targets targets.json --meta dataset/meta.csv --perm 2000 --controls faces
python regress_stage.py --voices voices.npz --labels labels.npz --targets targets.json --meta dataset/meta.csv --perm 2000 --exclude 1,2,8
```
Поради користувачу: зберігати вивід у `logs/<крок>_<дата>.txt` через `| tee`, щоб не копіювати в чат.
